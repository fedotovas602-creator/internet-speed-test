# Internet Speed Test

Небольшой консольный скрипт на Python для измерения скорости скачивания ресурса по URL.

## Возможности

- Принимает URL через аргумент командной строки.
- Выполняет 10 HTTP(S)-запросов **последовательно**.
- Полностью считывает тело каждого ответа перед началом следующего запроса.
- Измеряет время каждого запроса и рассчитывает среднее время.
- Суммирует объём всех загруженных данных.
- Выводит среднюю скорость скачивания.

## Требования

- Python 3.9 или новее.
- Подключение к интернету.
- Дополнительные библиотеки не нужны: используются модули стандартной библиотеки Python.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте терминал в папке проекта.
3. Выполните команду:

```bash
python3 speed_test.py "https://example.com/image.jpg"
```

Вместо примера укажите прямую ссылку на файл или другой ресурс, который хотите скачать.

В Windows команда может выглядеть так:

```powershell
python speed_test.py "https://example.com/image.jpg"
```

## Пример вывода

```text
Запрос 1/10: 0.420 сек., 250000 байт
Запрос 2/10: 0.395 сек., 250000 байт
...
Запрос 10/10: 0.410 сек., 250000 байт

--- Результаты ---
Успешных запросов: 10
Среднее время запроса: 0.408 сек.
Общий объём скачанных данных: 2,500,000 байт
Общий объём: 2.500 MB
Средняя скорость скачивания: 0.613 MB/s
Средняя скорость скачивания: 4.902 Mbit/s
```

Числа в примере условные: фактические результаты зависят от сети и сервера.

## Единицы измерения

- Время — секунды (s).
- Объём — байты (B) и десятичные мегабайты (MB).
- Скорость — мегабайты в секунду (MB/s) и мегабиты в секунду (Mbit/s).
- Для расчётов используется десятичная система: **1 MB = 1,000,000 байт**, **1 Mbit = 1,000,000 бит**, **1 байт = 8 бит**.

Средняя скорость рассчитывается как общий объём скачанных данных, разделённый на суммарное время выполнения десяти запросов.

## Примечание

Скрипт измеряет скорость загрузки конкретного ресурса с конкретного сервера. На результат могут влиять производительность сервера, размер файла, задержка сети, кэширование и другие факторы. Поэтому это ориентировочное измерение, а не универсальный тест всей интернет-линии.
